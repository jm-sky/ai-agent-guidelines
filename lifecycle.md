# Lifecycle

| Krok | Co |
|---|---|
| 1️⃣ Vision | `docs/vision/` |
| 2️⃣ Roadmap | opcjonalnie `docs/roadmap/` (większy zakres) |
| 3️⃣ Research | **zanim budujemy** — gotowiec / wzorzec → `docs/research/` ([cost-tokens.md](cost-tokens.md)) |
| 4️⃣ Plan | `docs/plans/` (+ implementation-notes) |
| 5️⃣ Implement | kod + lint z configów projektu |
| 6️⃣ Review | `docs/reviews/` |
| 7️⃣ Verify | `verification needed` → `done` |

## Research (krótko)

| 🔍 | Sprawdź gotowiec / lepsze rozwiązanie / wzorzec **przed** planem i kodem |
|---|---|
| 📚 | Źródła: **~5 default**, do **~10** gdy uzasadnione; więcej = wyjątek z OK |
| 📎 | Wniosek → `docs/research/` |

## Statusy

`draft` · `todo` · `planned` · `in progress` · `done` · `verification needed`

## Intent

| „chcę …” | zatrzymaj na planie / omówieniu |
|---|---|
| „chcę, abyś …” | wolno iść w implementację |
