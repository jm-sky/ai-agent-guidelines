# Planowanie

## Kolejność

1. 👁️ **Wizja** → `docs/vision/`
2. 🗺️ **Roadmap** (opcjonalnie, większy zakres) → `docs/roadmap/`
3. 🔍 **Research** → `docs/research/` — gotowiec / wzorzec **zanim** plan w repo ([cost-tokens.md](cost-tokens.md): ~5 źródeł default, do ~10)
4. 📋 **Plan** → `docs/plans/` (`domain--id--title.md` lub data-slug)
5. 📎 **Implementation notes** → `docs/plans/implementation-notes/{id+title}-implementation-notes.md`  
   (ścieżki, symbole, dokładne wytyczne dla agenta przy implementacji)

## Nagłówek planu

Jak w [directory-structure.md](directory-structure.md): Status, Created, Domain, Roadmap, Depends on, Finished.

## Dyscyplina

| ⚠️ | AI nie „dorabia” kierunku bez review |
|---|---|
| 🔁 | Kilka rund pytań **zanim** plan trafi do repo (np. co poprawić? UX? performance?) |
| 📱 | Szkic planu często w ChatGPT (telefon) — agent w repo dopiero potem |
| 🔍 | Bez researchu (albo świadomego „nic nie znaleziono”) — nie domykaj planu |

Po planie: stop i czekaj na „chcę, abyś…”.
